# Dépendances de production pour mon image api/Dockerfile -- sous-ensemble du
# requirements.txt racine (qui reste la référence pour mon environnement de
# développement complet). J'exclus volontairement ici ce qui ne sert qu'en
# développement local, jamais à l'exécution de l'API ou des scripts
# analytics/*.py qu'elle relance en sous-processus (voir api/routers/admin.py) :
# jupyter (et toute sa chaîne de dépendances -- mes notebooks d'EDA, jamais
# importé par mon code applicatif), pytest/httpx (ma suite de tests), locust
# (mon test de charge). Cette distinction a réduit mon image de production de
# plus de 2 Go à un peu plus de 800 Mo -- un vrai gain une fois sur un serveur
# à 20 Go de disque, pas qu'une optimisation cosmétique.
